## 閱讀器與知識更新工作台

SSR／FSD：章節目錄、原文／整理摘要、搜尋命中及列印。需求清單：表格排序、來源追溯與全篩選CSV匯出。知識庫：人工新增／修訂、來源與確認狀態、AI草稿匯入及複核、歷史版本。

人工草稿保存在此裝置；發布共用版本須將網站產生的完整JSON提交至GitHub `loan/knowledge-updates.json`，等待Pages部署完成。AI自動排程尚未啟用；待複核AI內容不覆蓋知識卡。原文件圖片及附件未復原。

驗證：於倉庫根目錄執行 `node loan/scripts/check_reader.cjs`。

知識庫提供新增、修改、刪除與還原。儲存立即套用於此裝置；共用新增／修改／刪除／還原透過GitHub提交版本檔。刪除採保留原內容的可還原版本紀錄，不修改正式文件與案例。


## 業務知識挑戰（2026-10-12）

`challenge.html` 提供每回合最多10題、單選／多選、主題及依據篩選、提交後解析、錯題與間隔複習、個人練習紀錄下載。題庫`questions.json`首版28題，每題連結指定法條或SSR章節、頁碼、原文摘錄與核對日期。SSR題僅依收錄版本作答，不宣告最新上線規則。紀錄儲存在此瀏覽器，不提供跨裝置帳號同步。

題目增修必須保留唯一ID、增加題目version、更新bank_version；依來源改動重新核對答案、條文生效及SSR最終決議。來源失效、取消、衝突或待確認的內容應停用，不得自動生成為標準答案。來源SHA-256僅用於追溯版本，不能代替業務正確性判斷。

驗證：`node loan/scripts/check_challenge.cjs`。如暫存`sources/*.json`存在，也核對SSR摘錄、頁碼、行號和SHA-256。`?preview=1`是操作驗證模式，不讀寫正式練習紀錄。

題庫擴充至60題：通用放款24題、中信文件36題；其中10題計算，另有契約、還款、信保、利率、建檔與額度情境。可依主線及出題方式篩選。每題均保留来源、版本及適用條件；通用法規與產品文件差異不得混用。停用題可設enabled=false或改成非「來源已核對」狀態。
