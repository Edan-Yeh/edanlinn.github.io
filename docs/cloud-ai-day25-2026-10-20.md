## 補強
1. 非同步建立工作建議回傳 HTTP 202 與 Job ID。
2. Job Table 明確記錄 Pending、Running、Completed、Failed，並設計當機回收。
3. trade_Id 不足以區分同筆交易的不同分析，使用 tradeId + jobType + requestVersion 及唯一約束。
4. AI Timeout 2 秒須依服務延遲目標評估；Retry 3 次後隔離失敗工作並保留稽核資料。
5. AI 不得直接寫正式 Loan DB 或成績，Spring Boot 依權限及業務規則控制。
