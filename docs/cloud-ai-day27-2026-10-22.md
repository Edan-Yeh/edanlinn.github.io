### 解析與補強
- Features：僅使用預測當下已知的練習次數、歷史正確率、答題耗時、已完成單元；Label 可定義為下一週補強測驗未達標。不能使用未來考試成績、後續補強結果等造成 Data Leakage 的欄位。
- 以學生或時間區間分組，先切 Training/Validation/Test，確保同一學生或未來資料不洩漏；V1 可用 Logistic Regression 或 Decision Tree，先建立 baseline。
- 不平衡資料要看補強類別 Recall、Precision、F1、PR-AUC 和 Confusion Matrix；不要只看 Accuracy。
- Vue 顯示建議；Spring Boot 負責身分、RBAC、正式成績；FastAPI 只讀授權特徵並回傳推論及模型版本，不能直接寫正式分數。
- 低延遲推論用同步 API 並設合理 Timeout；失敗時顯示無法預測、保留原成績、記錄 request/model version；批次任務才需持久化 Job。
- 模型品質下降應回退前一個經驗證的模型版本，不等於 DB rollback；DB rollback 只針對同一交易中尚未提交的資料庫變更。已提交金融交易需依業務規則進行補償或沖正。
- 現階段先用 NAS/CPU 免費方案；當有持續負載、SLA、團隊維運、可用性或訓練算力需求時，再比較 SageMaker AI、Azure ML、Vertex AI 的總成本、權限與部署方式。
