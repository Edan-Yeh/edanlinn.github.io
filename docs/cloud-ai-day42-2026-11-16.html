④ 親自 Coding｜Health API + 自動測試（70%）

在專案 src/main/java 對應 package 下建立 HealthController.java（package 需與專案相符）。這是教學範例，請親自輸入、執行與測試，勿只複製文字當完成證據。

package dev.edan.banking_ai_platform;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;
import java.util.Map;

@RestController
public class HealthController {
    @GetMapping("/api/health")
    public Map<String, String> health() {
        return Map.of("status", "UP", "service", "banking-ai-platform");
    }
}

注意 package 名稱需對齊 Spring Initializr 產生的主程式 package（可將 artifact 改為 banking-ai-platform，其 Java package 通常為 banking_ai_platform）。

執行：

.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
# 另開 PowerShell
Invoke-RestMethod http://localhost:8080/api/health

再新增 src/test/java 同 package 的 HealthControllerTest.java：

package dev.edan.banking_ai_platform;

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;
class HealthControllerTest {
    @Test
    void healthShouldReturnUp() {
        var result = new HealthController().health();
        assertEquals("UP", result.get("status"));
        assertEquals("banking-ai-platform", result.get("service"));
    }
}
