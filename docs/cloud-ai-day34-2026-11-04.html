① 核心觀念：RBAC 不等於資料授權

登入只證明身分（Authentication）；角色授權（RBAC）決定可做的動作；資料範圍（Document ACL / Tenant Scope）決定可存取哪一筆內容。RAG 檢索與 Agent Tool Call 必須在可信後端強制檢查，不能相信 Vue 傳來的 role、tenant_id 或文件 ID。

② 點選架構元件

選擇元件查看安全責任。

跨雲對照：AWS IAM + Cognito / Verified Permissions、Azure Entra ID + Azure AI Search、GCP IAM + Vertex AI Search 可組成授權架構，但各服務的文件級過濾、身分傳遞與政策能力並非完全等價。先在 NAS Docker + Spring Boot + FastAPI + Postgres 使用合成資料實作。
