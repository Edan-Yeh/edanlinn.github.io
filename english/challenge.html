Baseline
① 聽懂問題意圖

不再用 Yes / Yeah 撐住對話；先抓 PM scope、duration、English usage、compensation 等關鍵意圖。

② 即時組完整句

從碎句改成「Direct answer → 2 個重點 → 停」，先求清楚，再求華麗。

③ 專業內容英文化

Developer → SA / Consultant → Delivery / PM 的真實故事，先用中文釐清，再做成可講的英文。

基礎單字｜Daily Vocabulary

同一批單字用不同方式練，並依長期熟悉度調整頻率：錯的 ＞ 猜的 ＞ 新的 ＞ 對的。答對會拉長複習間隔；如果其實是猜的，可直接標註，系統會提高後續出現頻率。

Active Chunks｜自然口說

把單字放進真正會說出口的句型裡，練習自然反應、連接與面試表達。

持續更新機制

題庫可以持續更新，但熟悉度、錯題、猜題、口說分數與複習排程都存在你的帳號雲端資料，不會因為網站版本更新重新從頭開始。

把學習狀況回傳給我

可以直接匯出 PDF 或 Excel。PDF 適合快速閱讀與分享；Excel 會拆成總覽、能力、弱點、單字熟悉度、題目熟悉度、口說紀錄、錯誤記憶與最近回合等工作表。原本的 Markdown 與 JSON 備份仍保留。

報告會使用目前帳號已同步的學習紀錄。

匯入新版題庫 / 還原進度

正式更新 GitHub Pages 時，只要替換 question-bank.js 就會得到新版題庫。也可用進度 JSON 在不同裝置還原學習紀錄。

聽力 / 練習設定

每一題固定提供「北美」與「印度」兩個播放按鈕。預設使用 1.00x 正常業界對話速度；需要時仍可手動放慢、加快或切回自適應。Natural / Neural 模式會優先挑選較自然的英文 voice；播放前也會自動把 I’ll / I’m / Let’s 這類智慧撇號轉成語音引擎較穩定的格式。

語音注意：錄音完成後會先使用瀏覽器即時轉文字；若不可用，就改用本機 Whisper。系統會先檢查轉錄可信度，可信度不足時先讓你確認或修正文字，再進行內容、完整度、結構、常見文法與語速評分。第一次使用本機 Whisper 需要下載模型，之後瀏覽器會快取。錄音本身仍只保留在目前頁面，不會自動上傳。
