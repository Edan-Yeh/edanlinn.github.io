MongoDB 2026-10-12：你的基線

這些是真實面試暴露出的問題類型，現在直接變成你的固定訓練素材。

Baseline
① 聽懂問題意圖

不再用 Yes / Yeah 撐住對話；先抓 PM scope、duration、English usage、compensation 等關鍵意圖。

② 即時組完整句

從碎句改成「Direct answer → 2 個重點 → 停」，先求清楚，再求華麗。

③ 專業內容英文化

Developer → SA / Consultant → Delivery / PM 的真實故事，先用中文釐清，再做成可講的英文。

基礎單字｜Daily Vocabulary

同一批單字用不同方式練：單字卡、選擇題、句型填空、北美／印度聽力。句型的繁體中文預設隱藏，需要時再點開提示。

Active Chunks｜自然口說

把單字放進真正會說出口的句型裡，練習自然反應、連接與面試表達。

持續更新機制

網站本身會自適應；內容版本則可以隨你新的面試、工作案例與弱項持續增加。

把學習狀況回傳給我

按「匯出學習報告」會產生 Markdown，包含技能等級、常錯題、使用提示次數、口說自評與近期回合。你把檔案丟回 ChatGPT，我就能依真實弱項擴充下一版題庫。

匯入新版題庫 / 還原進度

正式更新 GitHub Pages 時，只要替換 question-bank.js 就會得到新版題庫。也可用進度 JSON 在不同裝置還原學習紀錄。

聽力 / 練習設定

每一題固定提供「北美」與「印度」兩個播放按鈕。預設使用 1.00x 正常業界對話速度；需要時仍可手動放慢、加快或切回自適應。Natural / Neural 模式會優先挑選較自然的英文 voice。

語音注意：網站會優先尋找 Natural / Neural / Premium / Enhanced 類型的系統語音，並顯示實際使用的 voice 名稱。若 Windows / Brave 沒有 en-IN 印度英文語音，仍會 fallback 到可用英文 voice。語音自然度最終仍取決於你的 Windows / 瀏覽器已安裝哪些 Speech Synthesis voices。
